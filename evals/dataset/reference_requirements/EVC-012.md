# Эталонные требования — EVC-012

**Название теста:** Атомарность задач, трассируемость и запрет выдуманных сущностей
**Тип контекста:** Корректные требования для декомпозиции на атомарные задачи (PASS)
**Страница Confluence (эмуляция):** pageId = 3244034

---

## 1. Назначение фичи

Управление учётной записью абонента: аутентификация, политика пароля, блокировка, сессии, восстановление.

## 2. Функциональные требования

### FR-01. Вход
- Абонент входит по «логин (MSISDN) + пароль».
- При неверном пароле возвращается ошибка аутентификации (HTTP 401).

### FR-02. Политика пароля
- Минимальная длина — 8 символов, максимальная — 64 символа (границы включительно).
- Пароль содержит заглавные, строчные буквы и цифры.

### FR-03. Блокировка
- После 3 последовательных неудачных попыток учётная запись блокируется.
- Счётчик сбрасывается после успешного входа.
- Разблокировка — вручную администратором.

### FR-04. Сессия
- TTL сессии — 30 минут с момента последней активности.
- При смене пароля все активные сессии инвалидируются.

### FR-05. Восстановление доступа
- Восстановление пароля подтверждается SMS-кодом на привязанный MSISDN.

## 3. Бизнес-правила

| ID | Правило |
|:---|:---|
| BR-01 | Блокировка учётной записи не меняет статус SIM-карты. |
| BR-02 | События аутентификации пишутся в журнал аудита. |

## 4. Ожидаемая декомпозиция

Требования подлежат разбиению на атомарные задачи, каждая из которых:
- решает одну изолированную проблему и проверяема отдельно;
- трассируется к своему FR-ID;
- имеет проверяемый чек-лист критериев приёмки;
- указывает зависимости от других задач (например, FR-03 зависит от FR-01).
