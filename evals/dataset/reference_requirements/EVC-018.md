# Эталонные требования — EVC-018

**Название теста:** Телеком-правило: проверка баланса и статуса до/после операции
**Тип контекста:** Требования на смену тарифа с проверкой баланса (PASS)
**Страница Confluence (эмуляция):** pageId = 3244034

---

## 1. Назначение фичи

Смена тарифа и подключение услуги абонентом в личном кабинете.

## 2. Функциональные требования

### FR-01. Смена тарифа
- Абонент выбирает новый тариф и подтверждает смену.
- Смена тарифа тарифицируется: списание разовой стоимости перехода с баланса.
- При недостатке средств смена тарифа отклоняется с ошибкой.

### FR-02. Подключение услуги
- Абонент подключает услугу из каталога.
- Подключение тарифицируется согласно стоимости услуги.
- При недостатке средств подключение отклоняется.

## 3. Телеком-правила (обязательные для тест-кейсов)

- Каждый тест-кейс на изменение тарифа/услуги обязан содержать проверку **баланса и статуса абонента ДО операции**.
- Каждый такой тест-кейс обязан содержать проверку **баланса и статуса ПОСЛЕ операции**.
- Ожидаемое изменение баланса должно быть указано конкретной суммой.
- Обязателен негативный сценарий с недостатком средств.
- MSISDN — только маскированные (например, `+79991112233`).
- При наличии контекста CDR — проверить запись в биллинге.
