# Эталонные требования — EVC-004

**Название теста:** Противоречие в управлении пользовательскими сессиями
**Тип контекста:** Противоречивое управление сессиями (ожидается Quality Gate = FAIL)
**Страница Confluence (эмуляция):** pageId = 3244034

## 1. Назначение фичи

Управление пользовательскими сессиями абонента.

## 2. Функциональные требования

### FR-01. TTL сессии (раздел «Сессии», п. 3.1)
> «Время жизни сессии (TTL) — **30 минут** с момента последней активности.»

### FR-02. TTL сессии (раздел «Безопасность», п. 7.2)
> «Время жизни сессии (TTL) — **15 минут** с момента входа.»

### FR-03. Инвалидация при смене пароля (раздел «Сессии», п. 3.2)
> «При смене пароля **инвалидируются все активные сессии** абонента, включая текущую.»

### FR-04. Инвалидация при смене пароля (раздел «Безопасность», п. 7.3)
> «При смене пароля **текущая сессия сохраняется**; завершаются только прочие сессии.»

### FR-05. Параллельные сессии (раздел «Сессии», п. 3.3)
> «Абонент может иметь **неограниченное число одновременных сессий** на разных устройствах.»

### FR-06. Параллельные сессии (раздел «Безопасность», п. 7.4)
> «Одновременный вход с более чем **одного устройства запрещён**; новая сессия завершает предыдущую.»
