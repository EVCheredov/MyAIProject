# Эталонные требования — EVC-016

**Название теста:** Матрица переходов состояний для сессий и блокировок
**Тип контекста:** Корректные требования с состояниями (PASS), часть переходов не описана
**Страница Confluence (эмуляция):** pageId = 3244034

---

## 1. Назначение фичи

Управление состояниями учётной записи и сессии абонента.

## 2. Состояния

### 2.1. Учётная запись
- `Active` — активна, вход разрешён.
- `Blocked` — заблокирована, вход запрещён.
- `Unblocked` — ранее заблокированная, разблокирована администратором.

### 2.2. Сессия
- `Valid` — активна.
- `Expired` — истекла по TTL.
- `Revoked` — отозвана (принудительно).

## 3. Функциональные требования

### FR-01. Блокировка учётной записи
- После 3 последовательных неудачных попыток учётная запись переходит `Active → Blocked`.

### FR-02. Разблокировка
- Администратор переводит учётную запись `Blocked → Unblocked`; после разблокировки доступен вход.

### FR-03. Истечение сессии
- По истечении TTL (30 минут) сессия переходит `Valid → Expired`.

### FR-04. Отзыв сессии
- При смене пароля все активные сессии переходят `Valid → Revoked`.
- При блокировке учётной записи активные сессии отзываются (`Valid → Revoked`).

## 4. Матрица допустимых переходов

| Сущность | Из состояния | В состояние | Триггер |
|:---|:---|:---|:---|
| Учётная запись | Active | Blocked | 3 неудачные попытки |
| Учётная запись | Blocked | Unblocked | Разблокировка администратором |
| Сессия | Valid | Expired | Истечение TTL |
| Сессия | Valid | Revoked | Смена пароля / блокировка |

## 5. Недопустимые переходы (должны отклоняться)

| Сущность | Из состояния | В состояние | Ожидание |
|:---|:---|:---|:---|
| Учётная запись | Blocked | Active | Вход запрещён |
| Сессия | Expired | Valid | Использование запрещено, требуется повторный вход |
| Сессия | Revoked | Valid | Использование запрещено |
