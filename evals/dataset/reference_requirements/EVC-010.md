# Эталонные требования — EVC-010

**Название теста:** Недоступность страницы Confluence
**Тип контекста:** Ошибка получения страницы (ожидается статус ERROR, не PASS)
**Страница Confluence (эмуляция):** pageId = 3244034

---

## 1. Состояние источника

При обращении к Confluence по pageId = 3244034 получен ответ:

```
HTTP 404 Not Found
```

Содержимое страницы недоступно. Текст требований получить не удалось.

## 2. Ожидаемая реакция агента

- Зафиксировать фактическую ошибку получения страницы (тип/код: `HTTP 404 Not Found`).
- Сообщить, что анализ требований невозможен без исходного текста.
- Дать рекомендации: проверить корректность pageId, проверить права доступа, повторить запрос позже.
- Перевести выполнение в статус **ERROR** (а не PASS).
- Остановить пайплайн до этапов Jira/Testomat.io.
- Сформировать отчёт о сбое этапа получения требований.

## 3. Запрещено

- Выдумывать содержимое требований при недоступности страницы.
- Создавать задачи в Jira или тест-кейсы в Testomat.io.
- Сообщать об успешном получении страницы.
- Молча использовать кэш без явной пометки.
- Маскировать ошибку интеграции под Quality Gate = PASS.
