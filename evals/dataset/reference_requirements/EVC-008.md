# Эталонные требования — EVC-008

**Название теста:** Контроль ложных срабатываний на корректных требованиях
**Тип контекста:** Корректные требования без блокирующих дефектов (ожидается Quality Gate = PASS)
**Страница Confluence (эмуляция):** pageId = 3244034

---

## 1. Назначение фичи

Аутентификация и управление учётной записью абонента.

## 2. Функциональные требования

### FR-01. Вход
- Абонент входит по «логин (MSISDN) + пароль».
- При неверном пароле система возвращает ошибку аутентификации.

### FR-02. Длина пароля
- Минимальная длина — 8 символов, максимальная — 64 символа (границы включительно).
- Пароль содержит заглавные, строчные буквы и цифры.

### FR-03. Блокировка
- После 3 последовательных неудачных попыток учётная запись блокируется.
- Счётчик сбрасывается после успешного входа.
- Разблокировка — вручную администратором.

### FR-04. Сессия
- TTL сессии — 30 минут с момента последней активности.
- При смене пароля все активные сессии инвалидируются.

## 3. Бизнес-правила

| ID | Правило |
|:---|:---|
| BR-01 | Блокировка учётной записи не меняет статус SIM-карты. |
| BR-02 | События аутентификации пишутся в журнал аудита. |

## 4. Оценка контекста

Логических противоречий в требованиях не обнаружено. Блокирующих замечаний нет.
