# Эталонные требования — EVC-015

**Название теста:** Конкретность тестовых данных, маскирование и коды ошибок
**Тип контекста:** Корректные требования с точными значениями (PASS)
**Страница Confluence (эмуляция):** pageId = 3244034

---

## 1. Назначение фичи

Политика пароля, блокировка по попыткам, TTL сессии.

## 2. Функциональные требования

### FR-01. Политика пароля
- Допустимая длина — 8–64 символа (границы включительно).
- Пароль содержит заглавные, строчные буквы и цифры.

### FR-02. Блокировка по попыткам
- После 3 последовательных неудачных попыток учётная запись блокируется.

### FR-03. TTL сессии
- TTL сессии — 30 минут с момента последней активности.

## 3. Требования к тестовым данным

- Конкретные длины пароля для проверки границ: 7, 8, 9, 64, 65 символов.
- Конкретное число попыток: 2, 3, 4.
- Конкретные значения TTL на границе: 29:59, 30:00, 30:01.
- MSISDN только в маскированном виде, например `+79991112233`.
- Коды ошибок — только из контекста или стандарта 3GPP (например, HTTP 401 для неверных учётных данных).
- Для каждого шага обеспечить воспроизводимость, указать тестовые роли и предварительные состояния.

## 4. Запрещено

- Формулировки «ввести валидное значение» без конкретики.
- Реальные номера, ФИО и иные ПДн.
- Выдуманные коды ошибок.
- Неоднозначные ожидаемые результаты.
- Плейсхолдеры вместо конкретных значений.
