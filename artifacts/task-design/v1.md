### ЗАДАЧА: Реализовать аутентификацию абонента по MSISDN и паролю
* **Jira:** KAN-45 — https://polarnik21.atlassian.net/browse/KAN-45
* **Тип задачи:** Разработка
* **Покрываемые требования:** FR-01
* **Описание:** Вход абонента по MSISDN + пароль; успех → сессия; неверный пароль → HTTP 401 {"errorCode":"AUTH_INVALID_CREDENTIALS"}; ответ на неверный логин/пароль неразличим.
* **Предусловия / Зависимости:** FR-02 (верификация пароля); FR-03 (блокировка поверх счётчика).
* **Критерии приемки:**
  - [ ] Корректные MSISDN+пароль → активная сессия.
  - [ ] Неверный пароль → HTTP 401 {"errorCode":"AUTH_INVALID_CREDENTIALS"}.
  - [ ] Ответ на несуществующий MSISDN и на неверный пароль неразличим.
  - [ ] Пароль не возвращается в ответе API.

### ЗАДАЧА: Реализовать блокировку учётной записи и сброс счётчика попыток
* **Jira:** KAN-47 — https://polarnik21.atlassian.net/browse/KAN-47
* **Тип задачи:** Разработка
* **Покрываемые требования:** FR-03, BR-01
* **Описание:** 3 последовательных неудачных попытки → блокировка 30 мин; в блоке вход запрещён даже с верным паролем → HTTP 423 {"errorCode":"ACCOUNT_BLOCKED","retryAfterSeconds":<остаток>}; авто-снятие через 30 мин, счётчик обнуляется; администратор может снять вручную досрочно (аудит). Счётчик сбрасывается после успешного входа и после истечения блокировки.
* **Предусловия / Зависимости:** FR-01, FR-02; запись ручного снятия в аудит зависит от BR-03.
* **Критерии приемки:**
  - [ ] 3 неверные попытки → блокировка 30 мин.
  - [ ] В блоке с верным паролем → HTTP 423 {"errorCode":"ACCOUNT_BLOCKED","retryAfterSeconds":<остаток>}.
  - [ ] Через 30 мин — авто-снятие, счётчик = 0.
  - [ ] Успешный вход сбрасывает счётчик.
  - [ ] Администратор снимает блокировку досрочно; событие в аудите.

### ЗАДАЧА: Реализовать управление сессией (TTL, продление, инвалидация)
* **Jira:** KAN-48 — https://polarnik21.atlassian.net/browse/KAN-48
* **Тип задачи:** Разработка
* **Покрываемые требования:** FR-04
* **Описание:** TTL 30 мин с последней активности, каждая успешная операция продлевает; истечение → HTTP 401 {"errorCode":"SESSION_EXPIRED"}; смена пароля инвалидирует все сессии включая текущую; Logout завершает только текущую сессию.
* **Предусловия / Зависимости:** FR-01 (создание сессии), FR-02 (смена пароля).
* **Критерии приемки:**
  - [ ] Сессия истекает через 30 мин неактивности; операция продлевает TTL.
  - [ ] Истёкшая сессия → HTTP 401 {"errorCode":"SESSION_EXPIRED"}.
  - [ ] Смена пароля инвалидирует все сессии, включая текущую.
  - [ ] Logout завершает только текущую сессию.

### ЗАДАЧА: Реализовать восстановление доступа по SMS-коду
* **Jira:** KAN-49 — https://polarnik21.atlassian.net/browse/KAN-49
* **Тип задачи:** Разработка
* **Покрываемые требования:** FR-05
* **Описание:** Восстановление по SMS-коду на привязанный MSISDN; код действителен 5 мин; 3 попытки ввода, затем аннулирование и повторный запрос.
* **Предусловия / Зависимости:** канал доставки SMS; недоставка — FR-06.
* **Критерии приемки:**
  - [ ] Код на привязанный MSISDN, действителен 5 мин.
  - [ ] После 5 мин код не принимается.
  - [ ] 3 попытки ввода; после 3 неудачных — аннулирование.
  - [ ] После аннулирования требуется повторный запрос.

### ЗАДАЧА: Реализовать обработку ошибок аутентификации и SMS-доставки
* **Jira:** KAN-50 — https://polarnik21.atlassian.net/browse/KAN-50
* **Тип задачи:** Разработка
* **Покрываемые требования:** FR-06

  - [ ] Недоставка SMS → HTTP 502 {"errorCode":"SMS_DELIVERY_FAILED"}.
  - [ ] Повторный запрос SMS не ранее чем через 60 с.

### ЗАДАЧА: Тестирование инвариантности статуса SIM и баланса при блокировке
* **Jira:** KAN-52 — https://polarnik21.atlassian.net/browse/KAN-52
* **Тип задачи:** Тестирование
* **Покрываемые требования:** BR-02
* **Описание:** Блокировка не изменяет статус SIM и не влияет на баланс. Использовать сгенерированные маскированные MSISDN; проверка статуса и баланса до/после транзакции блокировки/разблокировки. Пароль-пример: SuperGsm2024.
* **Предусловия / Зависимости:** FR-03 (реализованная блокировка/разблокировка); доступ к статусу SIM и балансу.
* **Критерии приемки:**
  - [ ] Статус SIM до/после блокировки не изменился.
  - [ ] Баланс до/после блокировки не изменился.
  - [ ] Статус SIM и баланс не изменились после разблокировки (авто и ручной).
