# Спецификация Jira-задачи (Task Design)

## Созданная задача

### ЗАДАЧА: [Тестирование] Пагинация таблицы реестра абонентов — UI-компонент
* **Проект:** KAN (TestAI)
* **Ключ:** KAN-2
* **Тип задачи:** Тестирование (Задача)
* **Приоритет:** Low
* **Метки:** ui, pagination, testing, b2b
* **URL:** https://polarnik21.atlassian.net/browse/KAN-2

### Описание
Необходимо протестировать UI-компонент «Пагинация» в таблице реестра абонентов (Личный кабинет B2B-оператора связи, версия 1.1.0).

### Функциональные требования
1. Кнопки перехода между страницами таблицы.
2. Выпадающий список выбора количества строк на странице: 20, 50, 100 (по умолчанию — 20).
3. При переключении страниц фокус UI плавно скроллится к верхней границе таблицы.

### Критерии приемки (Acceptance Criteria)
- [ ] Корректное отображение кнопок навигации (вперёд/назад, номера страниц)
- [ ] Выбор количества строк из выпадающего списка (20/50/100) корректно меняет число отображаемых записей
- [ ] Значение по умолчанию — 20 строк на странице
- [ ] Плавный скролл к верхней границе таблицы при переключении страниц
- [ ] Пагинация корректно работает при разных разрешениях экрана
- [ ] Граничные тесты: одна страница, минимальное количество записей, максимальное количество страниц
