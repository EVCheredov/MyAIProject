# Jira Task Specification

### ЗАДАЧА: [Тестирование] Ручная корректировка баланса — лимит 5000 руб. для роли SupportOps
* **Тип задачи:** Тестирование
* **Jira Key:** KAN-1
* **Описание:** Провести тестирование функционала ручной корректировки баланса для роли Оператор поддержки (SupportOps) в соответствии со спецификацией «Личный кабинет B2B-оператора связи» v1.1.0.
  - Роль SupportOps имеет право на корректировку баланса с лимитом 5000 руб.
  - Доступны два типа операций: Начисление (credit) и Списание (debit)
  - Все действия должны логироваться с тегом роли
  - При превышении лимита UI блокирует отправку формы и выводит предупреждение
* **Предусловия / Зависимости:**
  - Доступ к аккаунту с ролью SupportOps
  - Доступ к аккаунту с ролью SuperAdmin (для проверки отсутствия лимита)
* **Критерии приемки (Acceptance Criteria):**
  - [ ] Позитивный сценарий: SupportOps может выполнить корректировку на сумму 2500.00 руб.
  - [ ] Граничное значение: SupportOps может выполнить корректировку на сумму 5000.00 руб.
  - [ ] Негативный сценарий: SupportOps НЕ может выполнить корректировку на сумму 5000.01 руб.
  - [ ] Негативный сценарий: SupportOps НЕ может выполнить корректировку на сумму 6500.00 руб. — ошибка PERM_302
  - [ ] Проверка лога: после успешной корректировки в Audit Log фиксируется запись с тегом роли
  - [ ] Отрицательная сумма: при попытке ввести 0.00 или отрицательное значение — валидация UI блокирует форму
  - [ ] SuperAdmin/BillingEng: проверка отсутствия лимита 5000 руб.
