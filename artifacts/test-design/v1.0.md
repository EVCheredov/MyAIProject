#### ТЕСТ-КЕЙС 1: Проверка отображения 20 строк по умолчанию
* **ID:** 4609d2ff
* **Тест-сьют:** UI-компоненты / Пагинация таблицы абонентов
* **Тип проверки:** Позитивная
* **Приоритет:** Normal
* **Предусловия:** В таблице реестра абонентов имеется не менее 25 записей
* **Шаги воспроизведения:**
  1. Открыть страницу «Реестр абонентов» в ЛК B2B-оператора
  2. Дождаться загрузки таблицы
  3. Проверить значение выпадающего списка количества строк
  4. Подсчитать количество отображаемых строк в таблице
* **Ожидаемый результат:** В выпадающем списке выбрано значение «20». В таблице отображается ровно 20 строк. Под таблицей присутствует пагинация.

#### ТЕСТ-КЕЙС 4: Навигация по страницам (вперёд/назад)
* **ID:** 66f9358c
* **Тест-сьют:** UI-компоненты / Пагинация таблицы абонентов
* **Тип проверки:** Позитивная
* **Приоритет:** Normal
* **Предусловия:** В таблице не менее 45 записей (3+ страницы при 20 строках)
* **Шаги воспроизведения:**
  1. Открыть страницу «Реестр абонентов»
  2. Нажать кнопку «Вперёд» (→) в пагинации
  3. Проверить отображение второй страницы
  4. Нажать кнопку «Назад» (←)
  5. Проверить возврат на первую страницу
  6. Нажать на номер страницы «3» (третья страница)
* **Ожидаемый результат:** Все кнопки навигации работают корректно. При нажатии «Вперёд» отображается вторая страница. При нажатии «Назад» — первая. При клике на номер страницы — соответствующая страница.

#### ТЕСТ-КЕЙС 5: Плавный скролл к верхней границе таблицы при переключении страниц
* **ID:** 8307f07d
* **Тест-сьют:** UI-компоненты / Пагинация таблицы абонентов
* **Тип проверки:** Позитивная
* **Приоритет:** Low
* **Предусловия:** В таблице не менее 25 записей, страница предварительно проскроллена вниз
* **Шаги воспроизведения:**
  1. Открыть страницу «Реестр абонентов» с 20 строками на странице
  2. Прокрутить страницу вниз на 200px
  3. Нажать кнопку перехода на следующую страницу
  4. Зафиксировать поведение скролла
* **Ожидаемый результат:** После переключения страницы происходит плавная анимация скролла к верхней границе таблицы. Скролл происходит с анимацией (не мгновенный скачок).

#### ТЕСТ-КЕЙС 6: Пагинация при отсутствии записей (0 строк)
* **ID:** 4969de1f
* **Тест-сьют:** UI-компоненты / Пагинация таблицы абонентов
* **Тип проверки:** Негативная / Граничные значения
* **Приоритет:** Low
* **Предусловия:** В таблице реестра абонентов нет ни одной записи (пустой результат поиска)
* **Шаги воспроизведения:**
  1. Открыть страницу «Реестр абонентов»
  2. Ввести в поиск заведомо отсутствующий ИНН (например, «000000000000»)
  3. Дождаться результатов
* **Ожидаемый результат:** Таблица отображает пустое состояние с сообщением «Нет записей». Пагинация скрыта или отображается как 1 страница с 0 записями. Кнопки навигации неактивны (disabled).
